# Analyse prédictive du temps de préparation des commandes

## Contexte
Projet Data Analytics appliqué à la logistique, visant à analyser et prédire le temps de préparation des commandes.

## Objectif
Construire un modèle prédictif permettant d’estimer le temps de préparation et d’identifier les écarts de performance.

## Outils utilisés
- Python
- Pandas
- NumPy
- Scikit-learn
- Excel

## Méthodologie
1. Importation des données
2. Nettoyage des données
3. Transformation des variables temporelles
4. Analyse descriptive
5. Modélisation avec régression linéaire
6. Comparaison entre temps réel et temps prédit
7. Analyse des écarts

## KPI analysés
- Temps réel
- Temps prédit
- Écart en minutes
- RMSE
- R²
- Taux de réalisation

## Résultats
- Identification des commandes lentes
- Mise en place d’un standard prédictif
- Amélioration du suivi de la performance logistique
